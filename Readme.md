# AQUAHUAYTA - Sistema Web de Gestión

Proyecto desarrollado para el curso Integrador de Sistemas II.

## Descripción

AQUAHUAYTA es una empresa dedicada a la comercialización de peces ornamentales, alimentos para peces, plantas acuáticas, alimento vivo y productos relacionados.

Actualmente, parte de la gestión de clientes y pedidos se realiza de manera manual y mediante WhatsApp, lo que dificulta la centralización y trazabilidad de la información.

## Solución propuesta

Desarrollar un sistema web interno que permita centralizar la gestión de:

- Clientes
- Productos
- Disponibilidad
- Pedidos
- Estados de pedidos
- Pedidos especiales
- Historial de operaciones
- Reportes

WhatsApp se mantendrá como canal de comunicación con los clientes, mientras que el sistema web permitirá gestionar internamente la información.

## Metodología

El proyecto utiliza Scrum como marco de trabajo ágil.

### Sprint 1
Objetivo: construir la base funcional del sistema mediante autenticación y gestión de clientes, productos y disponibilidad.

Historias priorizadas:
- HU01 - Iniciar sesión
- HU02 - Gestionar clientes
- HU03 - Gestionar productos
- HU04 - Consultar disponibilidad
